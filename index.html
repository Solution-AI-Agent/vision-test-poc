VISION AGENT · AN INTERACTIVE EXPLAINER

화면의 의미를 읽고,
다음 행동을 선택합니다.

Vision 기반 Agent의 차별점은 화면을 행동의 입력으로 삼는 데 있습니다. 현재 화면과 목표를 연결하고, 행동 뒤의 새 화면을 다시 관찰합니다.

일반 개념 자료 · 프로젝트 실험 미포함 개념 애니메이션 · 실제 모델 실행 아님
0:00 / 2:48

01 · 시각적 의미로 대상 찾기

텍스트뿐 아니라 아이콘의 모양, 위치, 주변 맥락을 함께 이용합니다. 구조 정보가 적은 Canvas나 이미지 중심 UI에도 적용할 수 있습니다.

인식과 위치 선택이 정확해야 합니다. 비슷한 아이콘이나 작은 글자에서는 틀릴 수 있습니다.

02 · 새 화면으로 다음 선택 바꾸기

처음 계획만 고정하는 대신, 행동 결과를 관찰한 뒤 계속 진행할지·대기할지·경로를 바꿀지 선택할 수 있습니다.

대화상자가 나타나는 장면은 이 관계를 설명하는 예시이며 실제 Agent 실행이 아닙니다.

03 · 보이는 결과를 자연어 요구와 대조

선택 상태·진행 상태·화면 전후 변화처럼 사용자에게 보이는 결과를 질문합니다. 기준 이미지가 없어도 현재 화면을 자연어 기준과 대조할 수 있습니다.

기준이 모호하면 판정도 모호해집니다. 결과에는 전후 화면과 이유를 남겨야 합니다.

04 · 화면을 공통 관찰 입력으로 사용

Web·데스크톱·모바일은 내부 구조가 달라도 화면을 공통 입력으로 사용할 수 있습니다. 실행에는 환경별 클릭·터치·키 입력 도구와 권한이 필요합니다.

동일 정확도나 모든 플랫폼의 자동 지원을 뜻하지는 않습니다.

기존 자동화와 함께 봐야 합니다.

DOM/API 기반 검사는 명확한 값·계약·반복 검증에 유용합니다. role·label locator는 위치가 바뀌어도 대상을 찾을 수 있습니다. Playwright는 기준 스크린샷 비교도 제공합니다. 따라서 시각 검증 자체를 Vision만의 독점 기능으로 설명하지 않습니다.

Vision은 구조 정보에 덜 의존하는 화면 해석과 자연어 검토를 더할 수 있습니다. 오판·지연·모델 비용과 민감한 화면의 전송 여부를 고려하고, 중요한 업무는 실행 범위와 검토 기준을 정해야 합니다.

출처와 해석 범위

2026-10-06 공식 문서와 연구를 확인했습니다. 화면·아이콘·연결선·판정 흐름은 직접 만든 설명용 도해입니다. 성능 수치, 고객 반응, 프로젝트 테스트 결과는 포함하지 않습니다.

  • Midscene: vision-driven GUI interaction and visual assertions — 화면의 모양/위치를 통한 대상 찾기, 자연어 작업 및 시각 확인, 플랫폼별 실행 어댑터
  • ScreenAgent research: planning, acting and reflecting — 관찰·계획·행동·재확인의 개념 구조; 특정 제품 성능으로 일반화하지 않음
  • Playwright: Locators — role/label/test ID 등 구조 기반 위치 찾기; 레이아웃 변화에도 locator가 작동할 수 있음
  • Playwright: Visual comparisons — 기준 스크린샷 비교 기능; 시각 검증은 Vision만의 독점 기능이 아님

애니메이션의 흐름과 네 가지 분류는 위 자료를 종합한 설명 구조입니다. 특정 모델이 모든 장면에 성공한다는 실증 결과가 아닙니다.
