## 이번 변경

알림 끄기라는 하나의 목표로 화면 관찰 → 행동 선택 → 결과 확인을 설명합니다. 기본 화면·설정 위치 변경·팝업 등장 시나리오와 결과 비교를 직접 조작할 수 있습니다. 모양·공간 관계·상태를 구분해 보여주고 모바일 표시를 지원합니다.

인터랙션은 동작을 미리 구성한 개념 시연이며 실제 모델 실행이나 성능 측정이 아닙니다. 프로젝트의 테스트 화면·실측 결과를 사용하지 않았습니다.
