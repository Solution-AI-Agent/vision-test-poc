제작 한계/구분:
- 현재 유료 모델 실행이 아니라 저장된 실제 결과를 편집. 신규 모델 호출 0.
- 실제 녹화 24–36초(1배속), 37–65초(2배속), 77–101초(2배속)를 사용.
- 원본을 6fps로 샘플링한 녹화 구간을 24fps 영상에 합성. 원본 WebM 보존.
- 그 외는 실제 캡처 확대, 편집 설명 카드/도식/주석. 응답을 합성하지 않음.
- 한국어 주문 성공 1회, 과거 선별 통제실험, 최신 혼합 검사 결과를 구분.
- 최신 겹침 모델 해석 정확도 0/3과 주문 실행 중 정상 차트 오탐을 자료에 명시.
- 일반 우위/완전 자율 발견/모든 사이트에서의 안정성/Windows 검증을 주장하지 않음.
- Playwright screenshot 검증도 해당 결함을 잡을 수 있음을 영상에서 명시.

제작 중 시행착오:
초기 Chromium WebM 프레임 추출은 흰 프레임으로 나와 사용하지 않았음.
FFmpeg VP8 디코딩으로 원본을 읽어 실제 입력 변화를 직접 확인 후 사용.
