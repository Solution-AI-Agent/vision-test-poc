# 영상·HTML 자료

```sh
npm run media:serve
```

브라우저에서 http://127.0.0.1:4312/media/index.html 을 열면 두 영상, 대본, 검수 기록, 독립 샘플사이트 갤러리를 확인할 수 있습니다. `index.html`은 `file://`로 직접 열어도 상대 경로를 사용합니다. GitHub 파일 보기에서는 HTML이 렌더링되지 않을 수 있습니다.

- `v5/`: 최종 차별점 설명, 160초. 통합 `/demo`의 선택한 영수증 가림 사례
- `v4/`: 이전 YouTube 기반 설명, 168초. 성공과 판독 실패를 함께 담은 실험 기록
- 두 영상은 1280×720, 한국어 자막, 무음. 이후 별도 4311 샘플사이트의 Vision 검출을 검증한 영상이 아닙니다.

영상·대본·HTML·출처·제작 소스의 원본 바이트를 보존했습니다. 편집기 임시 `.sb-*` 파일은 배포하지 않습니다. 각 버전 내부 인계 문서, `FILES_SHA256.txt`, 제작/검증 스크립트는 **당시 워크스페이스 기록**이므로 원래 `OUTBOX/` 경로나 임시 파일을 참조할 수 있습니다. 현재 clone의 파일 무결성은 저장소 루트에서 `npm run evidence:check`로 확인하세요. 영상 제작 스크립트의 다른 OS 재실행은 이번 배포 범위에 포함하지 않았습니다.
