# 보관된 테스트 데이터

이 디렉터리는 2026-10-04~05에 수행한 실험과 로컬 검증의 기록입니다. 새 장비에서 모델을 호출하지 않고 원본·로그를 검토할 수 있습니다. 새 실행 결과나 현재 코드의 성공률로 해석하지 마세요.

```sh
node evidence/restore.mjs --check  # 원본 해시 확인
node evidence/restore.mjs          # 루트 artifacts/와 .data/로 복원, 유료 호출 없음
```

복원 후 플랫폼을 실행하면 실행 기록과 `/demo`의 저장된 실제 판정·원본 링크를 확인할 수 있습니다. 기존 로컬 데이터가 다르면 덮어쓰지 않고 중단합니다. 깨끗한 checkout에서 복원하는 것을 권합니다. API 키·모델 인증 설정은 포함하지 않았습니다.

- [전체 자료 안내](../media/index.html): 영상·대본·화면 갤러리·실행 기록
- [독립 샘플사이트 여섯 상태](SCREENS.html): 정상, 정렬, 가림, 잘림, 상품 이미지, 차트
- `recordings/`: 원본 PNG/JPEG/WebM, 실제 공급자 원응답·모델 입력, 로컬 테스트와 모의 공급자 테스트
- `runtime/runs.json`: 플랫폼이 저장한 실행 기록. 실패·미완료 기록도 포함
- `runtime/scenarios.json`: YouTube와 독립 샘플사이트 등록 시나리오
- `runtime/demo-call-ledger.json`: 과거 데모의 사용된 호출 한도. 재호출 승인이 아님
- `reviews/`: 당시 독립 검토 기록
- `MANIFEST.json`: 출처 경로·바이트 수·SHA-256. 출처의 과거 절대/워크스페이스 경로는 이력이며 현재 장비 링크가 아님

| 통제 사이트 4×3 | `controlled-evaluation-2026-10-05T00-07-05-778Z/` | 작은 두 결함 각각 3/3 미탐 |

| 독립 샘플사이트 | `standalone-sample-2026-10-05T11-57-19-450Z/`, `standalone-sample-2026-10-05T12-09-24-086Z/` | 여섯 상태 기능 PASS. 새 사이트의 실제 Vision 검출은 미검증 |

`stub`, `STUB_REPORT`, `ui-check`, 테스트용 공급자 기록은 모델 성능 증거가 아닙니다. 요청 전 장애는 유효한 모델 판정과 분리합니다. 비용은 공급자 응답 보고값이며 실청구액 보증이 아닙니다. 일반 성능·완전 자율 결함 발견·Windows 검증을 주장하지 않습니다.

원본 내용은 보존했습니다. JSON 안의 `/artifacts/...` URL는 복원 후 플랫폼에서 열립니다. 공개 화면 캡처와 합성 주문 데이터가 포함됩니다. 일부 과거 인계 문구는 당시 상태를 설명하므로 이후 독립 검토 기록과 함께 읽으세요.
