- `act-final.png` 직접 확인: 빨간 머그 선택, 수량2, 김성지, 이메일 placeholder가 남은 빈 칸. 주문 입력 폼이어서 주문 미완료.

## 후속 결정

POC_MAKER에 기존 실험기의 명시적 옵션으로 일반 placeholder/입력 상태 지침만 추가하는 최소 비교 준비를 맡김. 사용자 원문을 유지하고 별도 지침/전송 내용을 기록한다. DOM/고정좌표·정답 주입·자동삭제·임의 단계 분해·다른 모델 없이 동일 한도를 유지한다. 추가 유료 호출이나 운영 앱 반영은 맡기지 않았으며 모의 요청 검증·전체 테스트/빌드 후 독립 재검토한다.
