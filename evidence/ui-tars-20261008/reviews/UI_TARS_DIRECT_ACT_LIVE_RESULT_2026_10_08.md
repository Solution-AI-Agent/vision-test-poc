## 실패와 후속 가설

요청10 원응답 `click(start_box='(465,731)')`가 1288×728 리사이즈 픽셀 좌표계 밖이라 어댑터가 차단했다. 직전 이름 선택 원응답은 `(175,532)`이고 SDK용 변환은 `[136,731,136,731]`이었다. 후속 모델 요청의 행동 이력에 SDK용 정규화 좌표가 다시 전달돼 픽셀 좌표와 혼용되는지 오프라인 재현할 필요가 있다. y731 일치는 단서이며 원인 확정은 아니다.

요청 이미지 수는1→10장, 마지막 입력13,808토큰. 현재는 성능 최적화가 아닌 좌표 계약 검증에 집중한다.

POC_MAKER에게 결과와 후속 오프라인 진단/최소 수정을 위임했다. 모델 이력의 좌표와 실행기 좌표를 분리할 필요가 있는지 실제 SDK 요청 캡처로 확인하고, 임의 좌표 보정 없이 전체 테스트/빌드를 보고받는다. 추가 유료 호출·운영 서버/설정 변경은 위임하지 않았다.
