## 보완 수락 기준

POC_MAKER가 기존 구현 이슈에서 다음 범위를 이어서 처리한다.
- 입력 전 현재 화면에서 대상을 선택하고 포커스를 확보한다. 사이트 고정 좌표/검색어/locator fallback은 쓰지 않는다. 구현 형태는 담당자 판단.
- 요청된 행동, 도구 호출 완료, 화면에서 관찰된 상태를 구분한다. 빈 검색창을 입력 성공으로 서술한 재현을 회귀 검증한다. 모델의 입력 완료 주장을 그대로 신뢰하지 않는다.
- 로컬 no-focus fixture로 조용히 유실된 입력을 검증한다. DOM은 독립 테스트 정답에만 사용할 수 있고 제품 Vision 계획에는 공급하지 않는다.
- 재계획 및 추가 검증도 기존 실행 한도 안에 포함한다. 복합 입력 액션을 쓰면 실제 내부 행동을 누락 집계하지 않는다.
- 로컬 검증 후 사용자가 지정한 같은 모델과 기존 설정 상한 내에서 자율 모드 한 회를 재검증하고 보고한다. 동일 실패를 끝없이 재호출하지 않는다.
- 단일 자율 업무 완료가 이루어져도 실제 결함 발견이나 전체 탐색 커버리지로 확대하지 않는다.

## 영상 인계

현재 고정 실측은 초기 실험의 성공/실패 증거로 사용 가능. LUMEN에는 최종 등록 수치와 자율 실패, 화면 상태 오인 사례를 전달한다. 추가 보완 실측은 별도 버전으로 반영한다. Windows와 편집 영상은 미완료. PR 병합 및 이슈 종료는 하지 않았다.
