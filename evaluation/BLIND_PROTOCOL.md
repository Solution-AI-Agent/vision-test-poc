# Frozen blind extraction protocol v1

Existing acceptance source: CRITERIA.json at ed76daf, unchanged. Comparator uses the receipt line amounts 32/16/0, total 48, and the three verbatim delivery instructions from that file. Neutral model prompt/schema are in server/blind-extraction.ts; expected values only occur in the comparator function, never the prompt. Strict parsing; uncertain/missing fields are inconclusive unless another clear localized violation exists. Extraction correctness must be independently reviewed; comparator candidate alone is not a detected defect.

Use original stored JPEG bytes, one per state, in scripts/blind-evaluate.ts. Fixed order normal/clipped/total/decoration/total/normal/decoration/clipped/decoration/total/clipped/normal. State labels and integrity hashes exist only in local experiment records. No new capture, crop, history, DOM, oracle, retries or model changes. One request/trial, 30 seconds, 2048 tokens; batch cap 12. All outgoing text and image hashes recorded before transport. Authentication/provider blocker stops remaining slots. Midscene screenshot source replaced with original data URL, validated byte-for-byte by a local SDK stub test. The test creates its own JPEG solely to verify transport and does not supply evaluation inputs.

Run npm test and npm run build before paid calls. Then OPENROUTER_API_KEY in process environment npx tsx scripts/blind-evaluate.ts. Never commit or export key. Preserve all raw outputs and original matrix. Gate: normal 3/3 without false positives, at least one defect correctly transcribed/localized/identified 3/3; disclose benign and misses. No retries if gate fails.
